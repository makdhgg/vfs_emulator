# Документация по VFS - Virtual File System

VFS (Virtual File System) - это эмулятор файловой системы с графическим интерфейсом, написанный на Python с использованием Tkinter. Приложение имитирует работу командной оболочки с базовыми командами для навигации по виртуальной файловой системе.

## Основные возможности

Графический интерфейс терминала с черным фоном, белым текстом и зеленым приглашением ввода. Поддержка базовых файловых команд: ls, cd, exit, help. Раскрытие переменных окружения в аргументах команд. История введенных команд. Автоподстановка информации о системе (имя пользователя, hostname).

## Функциональные компоненты

VFSEmulator класс - основной класс приложения, управляет состоянием файловой системы и интерфейсом. Содержит текущую директорию и историю команд.

setup_gui() - инициализирует графический интерфейс, включая область вывода с прокруткой, поле ввода команд с приглашением и кнопку выполнения.

print_output() - выводит текст в основную область вывода, автоматически прокручивая к новому контенту.

expand_environment_variables() - раскрывает переменные окружения в аргументах команд, поддерживая экранирование символов.

parse_command() - парсит введенную команду, разделяя на команду и аргументы с обработкой переменных окружения.

execute_command() - выполняет распарсенную команду и выводит результаты в интерфейс.

## Поддерживаемые команды

ls - вывод содержимого текущей директории (заглушка). Показывает фиктивные файлы: file1.txt, file2.txt, directory/, document.pdf.

cd <директория> - смена текущей директории (заглушка). Поддерживает раскрытие переменных окружения: cd $HOME/documents.

exit - завершение работы приложения.

help - вывод справки по доступным командам и возможностям.

## Запуск приложения

Для запуска требуется Python 3.x с установленной библиотекой Tkinter.

Запуск из командной строки: python vfs_emulator.py

После запуска откроется окно с интерфейсом терминала, готовое к вводу команд.

## Примеры использования

Ввод команды ls:

user@hostname:~$ ls
ls: вывод содержимого директории '/'
file1.txt  file2.txt  directory/  document.pdf


Смена директории с переменной окружения:

user@hostname:~$ cd $HOME/documents
cd: смена директории на '/home/user/documents'
Текущая директория: /home/user/documents


Получение справки:

user@hostname:~$ help
Доступные команды:
  ls - вывод содержимого директории (заглушка)
  cd <директория> - смена директории (заглушка)
  exit - выход из VFS
  help - эта справка

Поддерживается раскрытие переменных окружения:
  cd $HOME/documents  # Перейдет в /home/user/documents


## Особенности реализации

Интерфейс использует моноширинный шрифт Courier New для аутентичного вида терминала. Поддержка экранирования символов доллара: \$HOME не будет раскрываться как переменная. Автоматическое определение имени пользователя и hostname системы для отображения в приглашении. Поле ввода команд поддерживает выполнение по нажатию Enter или клику на кнопку "Выполнить".

Приложение представляет собой прототип REPL (Read-Eval-Print Loop) системы и служит основой для расширения функциональности виртуальной файловой системы.
